Promemoria oratori

I dati sono salvati su GitHub, cifrati. Inserisci la password per aprirli.

Prima configurazione: i dati verranno salvati nel file dati.json del repository, cifrati con una password che scegli tu.

  1. Apri github.com/settings/personal-access-tokens/new
  2. Nome: promemoria-oratori; scadenza a piacere
  3. Repository access → Only select repositories →
  4. Permissions → Contents: Read and write
  5. Genera il token e incollalo qui (viene salvato cifrato con la password)

Messaggio predefinito

Il testo di partenza per ogni oratore. Puoi comunque modificarlo per il singolo oratore prima di inviarlo.

Automazioni dall'iPhone

Con l'app Comandi dell'iPhone, ogni lunedì:

  • alle 8:30 ricevi una notifica con gli oratori da avvisare quel giorno, così puoi mandare anche il messaggio WhatsApp;
  • alle 9:00 (se attivi gli SMS automatici) parte da solo un SMS con il messaggio qui sopra. Chi hai già avvisato viene saltato.

Tieni per te questi indirizzi: chi li ha vede i messaggi della settimana. Controlla che funzionino (mostra i prossimi SMS, non invia niente).

Automazione 1 — notifica alle 8:30
  1. App Comandi → Automazione → + → Ora del giorno: 8:30, Ogni settimana, solo lunedì. Scegli Esegui immediatamente → Avanti → Nuova automazione vuota.
  2. Aggiungi Ottieni contenuti dell'URL e incolla l'indirizzo per la notifica.
  3. Aggiungi Se: Contenuti dell'URL ha qualsiasi valore.
  4. Dentro il «Se» aggiungi Mostra notifica con testo Contenuti dell'URL e titolo «Promemoria oratori».
  5. Tocca Fine. Per aprire l'app al volo, aggiungila alla schermata Home da Safari (Condividi → Aggiungi a Home).
Automazione 2 — SMS alle 9:00
  1. App Comandi → Automazione → + → Ora del giorno: 9:00, Ogni settimana, solo lunedì. Scegli Esegui immediatamente → Avanti → Nuova automazione vuota.
  2. Aggiungi Ottieni contenuti dell'URL e incolla l'indirizzo per gli SMS.
  3. Aggiungi Ottieni valore del dizionario: Valore per la chiave messaggi in Contenuti dell'URL.
  4. Aggiungi Ripeti con ogni elemento in Valore del dizionario. Dentro la ripetizione:
    1. Ottieni valore del dizionario: chiave testo in Elemento ripetizione
    2. Invia messaggio: messaggio = Valore del dizionario; destinatari: tocca il campo, scegli Elemento ripetizione, poi chiave telefono. Apri la freccia dell'azione e disattiva Mostra quando eseguito.
    3. Ottieni valore del dizionario: chiave conferma in Elemento ripetizione
    4. Ottieni contenuti dell'URL: URL = Valore del dizionario (segna l'oratore come avvisato nell'app)
  5. Tocca Fine. Se gli SMS automatici sono disattivati qui sopra, l'automazione non invia niente.

Il lunedì mattina l'iPhone deve essere acceso e collegato a internet.

Anteprima

Con il primo discorso in programma.

1. Programma dei discorsi

Il file esportato, in formato CSV o Excel (.xlsx).

2. Oratori

Il file ZIP con un file per congregazione (CSV o Excel), oppure uno o più file CSV/Excel. In un file Excel con più fogli, ogni foglio può essere una congregazione.

Salvataggio su GitHub

Programma, oratori, messaggi e invii sono salvati cifrati nel file dati.json del repository : li ritrovi da qualsiasi dispositivo con la password. Quando esporti un programma aggiornato, ricaricalo qui: gli invii già fatti vengono mantenuti.

Sicuro? Si cancellano programma, oratori e invii anche su GitHub.
